# ✊ Stone Paper Scissors Game

A console-based Stone Paper Scissors game developed using **C++**.

The game allows the player to compete against the computer across multiple rounds, with colored screen effects and a final score summary.

## 🎮 Game Features

- Choose the number of rounds to play.
- Play against the computer.
- Random computer choices.
- Display results after each round.
- Colored console screen based on the round winner:
  - 🟢 Green: Player wins.
  - 🔴 Red: Computer wins.
  - 🟡 Yellow: Draw.
- Sound alert when the computer wins.
- Display final game statistics.
- Option to play again after the game ends.

## 🛠️ Technologies Used

- C++
- Enums
- Structures (Structs)
- Functions
- Random Number Generation
- Loops and Conditional Statements

## 📊 Game Results

At the end of the game, the program displays:

- Total number of rounds.
- Player wins.
- Computer wins.
- Draws.
- Final game winner.
